# Hyperboard

## Session log

After making changes in a session, append an entry to `docs/SESSION_LOG.md` before ending the turn:

- Add a new `## YYYY-MM-DD HH:MM` heading at the top (above the previous entry, below the format block). Run `date '+%Y-%m-%d %H:%M'` to get the timestamp — don't guess.
- List what changed as bullets. Feature-level or file-level is fine; skip noise like "ran tests".
- Skip the entry entirely if the session made no code or doc changes (pure exploration / questions).
- One entry per session. If you've already written one this session and make more changes, edit that entry rather than adding a second.
